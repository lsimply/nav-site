# 精选导航 · 数据管理

页面文件 `index.html` 只负责展示，所有站点都在 `sites.js` 里。增删改站点只改这个文件，不用动页面。

## sites.js 结构

文件开头是 `window.SITES_DATA = `，后面是下面这样的数据，末尾有一个分号。

```js
window.SITES_DATA = {
  "updated": "2026-11-18",
  "categories": [
    { "id": "tools", "name": "效率工具", "note": "一句你的使用心得，可以留空" }
  ],
  "items": [
    {
      "c": "tools",
      "name": "站点名",
      "icon": "image",
      "url": "https://example.com",
      "desc": "一句话说明为什么好用",
      "tags": ["免费", "新增"],
      "pin": true
    }
  ]
};
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `c` | 是 | 分类 id，必须是 `categories` 里已有的 |
| `name` | 是 | 站点名 |
| `url` | 是 | 以 `https://` 开头，同一个网址不要重复 |
| `icon` | 否 | 两种写法：图标名（可选值见 `index.html` 里的 `ICONS`），或图片地址，比如 `"https://example.com/favicon.png"`、`"icons/chatgpt.svg"`（相对路径，图片放在同一目录下）。不写或图片加载失败时显示链接图标 |
| `desc` | 否 | 简介，建议 30 到 60 字，写“为什么好用” |
| `tags` | 否 | 标签。`新增` 显示蓝色，`热门` 显示橙色，出现 2 次以上的标签会自动进入筛选栏 |
| `pin` | 否 | 设为 `true` 时可进入首页“热门推荐”（带 `热门` 标签的站点优先） |

## 日常操作

- **加站点**：在 `items` 里复制一行，改内容，注意逗号。
- **改分类顺序**：调整 `categories` 的顺序，页面和左侧栏同步变化。
- **新增标记**：新站点加标签 `新增`，一个月后去掉。
- **每次修改后**：把 `updated` 改成当天日期。

## 用在线表格管理（可选）

不想改代码文件时，可以把站点放进在线表格，页面会自动读取。

1. 把 `sites.csv` 导入在线表格（Google 表格：文件 → 导入 → 上传）。第一行是表头，保持不变。
2. 在表格里“发布到网络”，格式选 **CSV**，复制生成的链接。Google 表格的路径是：文件 → 共享 → 发布到网络。
3. 打开 `sites.js`，把链接填进第一行的 `window.SHEET_URL = ""` 引号里。
4. 以后在表格里增删改，刷新页面就能看到，不用再动文件。

表格列：

| 列 | 说明 |
|---|---|
| 分类 | 必填，同名的行归为一个分类，分类顺序按第一次出现的顺序 |
| 站点 / 网址 | 必填，网址要以 `https://` 开头 |
| 图标 | 可选，图标名或图片地址 |
| 简介 | 可选，一句话说明为什么好用 |
| 标签 | 可选，多个标签用“、”或逗号隔开，比如 `免费、新增` |
| 置顶 | 可选，填“是”进入首页热门推荐 |
| 分类说明 | 可选，写在该分类的任意一行，显示在分类标题下面 |

注意：
- 表格读取失败（网络不通、链接错了）时，页面会自动改用 `sites.js` 里的本地数据，所以本地数据建议保留一份。
- 表格发布后，更新通常有几分钟延迟。
- Google 表格在中国大陆可能需要特殊网络才能访问，访问者那边读不到时同样会退回本地数据。如果你的主要读者在国内，建议继续用 `sites.js`，或者把表格定期导出覆盖。
- “发布到网络”意味着任何人拿到链接都能看到表格内容，不要放不想公开的东西。

## 检查

- **格式**：改完 `sites.js` 后打开页面，如果提示“站点数据 sites.js 没有加载成功”，多半是对象里漏了逗号或引号，或者末尾的分号被删掉了。
- **重复和失效**：每月随手点开几个，打不开的就删掉。不需要任何脚本。

## 部署

整个目录是纯静态文件，三个文件放在同一个目录，双击 `index.html` 就能在本机打开，放到 GitHub Pages、Cloudflare Pages 或任意静态服务器即可。用 GitHub 的话，可以直接在网页或手机 App 里编辑 `sites.js`，保存后网站自动更新，并保留每次修改记录。
